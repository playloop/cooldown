# 0.2.0

Expansion playtest, October 24, 2026. Ten rooms replace the original four-room
progression. The original episode tags are unchanged.

- Local, persistent-per-attempt ice carving with shared visual/collision cells.
- One-charge refills, normalized diagonals unlocked at room 6, and one-way ramps.
- Seekers with visible target commitment, wall stops, recovery, and swept contact.
- Main routes with resting shelves and optional faster aerial chains.
- Room-specific teaching text and a visible dash-ready state.
- The old mandatory hard-gap assertion is deliberately replaced by progression
  and timing-tolerance checks. The fall-short death regression retains its old
  geometry as a test fixture.
- A review caught diagonal wall sliding that distorted streaks. Dashes now stop
  at first contact along their actual segment, with wall and ceiling regressions.

Validation: full check, room routes, keyboard input, independent code review,
and actual browser play. The private package has telemetry disabled. Human
playtesting will determine whether the difficulty and pacing feel right.
